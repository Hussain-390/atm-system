# 🏧 ATM Management System

A Java-based ATM Management System developed using Java Swing, JDBC, and MySQL.
This desktop application simulates core ATM functionalities such as account creation, authentication, transactions, balance enquiry, and PIN management.

---

## 🚀 Features

* 🔐 User Signup & Login Authentication
* 💰 Deposit and Withdraw Money
* ⚡ Fast Cash Feature
* 📄 Mini Statement Generation
* 🏦 Balance Enquiry
* 🔑 PIN Change Functionality
* 🗄️ MySQL Database Integration
* 🖥️ Responsive Java Swing GUI

---

## 🛠️ Tech Stack

* Java
* Java Swing
* JDBC
* MySQL
* NetBeans IDE

## ⚙️ Database Setup

### 1️⃣ Create Database

```
CREATE DATABASE bankmanagementsystem;
```

### 2️⃣ Import SQL File

Import the provided `database.sql` file using MySQL Workbench.

---

## ▶️ Run the Project

### Using NetBeans

* Open the project in NetBeans
* Clean and Build Project
* Run `Login.java`

### Using JAR File

```
java -jar ASimulator.jar
```
